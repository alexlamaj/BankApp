# BankApp
Personal Project built with educational purpose and training. A banking app project which starts with a landing page and then proceeds to the App. Built entirely with HTML, CSS, and JavaScript, using node.js for the npm server.

Idea generated by Jonas Schmedtmann's JavaScript Course

Development Server
---------------------
Run ng start in your terminal to start a dev server. Visit the https://localhost:3000/ in order to view the project. The application saves automatically all the changes provided.

Built-with
---------------------
Coded with HTML for the structure, CSS for the styling, and JavaScript for the data and event handlers.
